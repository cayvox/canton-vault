# Share registry requirements

Every MUST and SHOULD of the Canton Token Standard V2 that applies to the share registry of `cvx-vault-v1` (D-07; SPEC §4.3, §8), with where it is implemented and which test proves it. Each requirement links to its text in the Splice sources at tag `0.8.4` (commit `fa6b029f`), under `token-standard/`, or in CIP-0112 at commit `ef039e9a` of `canton-foundation/cips`; a bare `:n` is a line of the file named in the section heading. Implementation paths are relative to `packages/token/vault-v1/daml/Cayvox/VaultV1/Internal/`; tests are in `test/vault-v1-test`.

The registry is the instrument admin's registry for one share instrument: `InstrumentId {admin = operator, id = <vault identifier>}`. Its templates are `ShareRules` (the factories), `ShareHolding`, `ShareAllocation`, `ShareTransferInstruction` and `ShareEventLog` (`ShareRegistry.daml`); the token standard rules it implements itself, in place of a production dependency on `splice-token-standard-utils`, are in `TokenStandard.daml`. Every failure has an identifier `cayvox.com/registry-...` and category `InvalidGivenCurrentSystemStateOther` (D-13, `Failure.daml`).

A requirement on another role (an app, a wallet, the executors) is listed only where the registry must support it.
