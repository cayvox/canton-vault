# Conventions

These are the conventions of OpenZeppelin/canton-contracts at commit `aeca01d` (`aeca01d043311d8ccc8ab7cda4d7c16e682429fa`, its `main` after PR 48 was merged on 30 September 2026), restated so that this repository can be contributed without restructuring. Each source links the file and lines at that commit. Where this repository differs, the row says how, and the difference is either a working name (D-17) or listed under "Differences" at the end.

## 1. Packages

| Rule | Source |
|---|---|
| One independently released unit is one Daml package and one DAR. Unrelated components are never bundled. | [`AGENTS.md:30`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/AGENTS.md#L30), [`ARCHITECTURE.md:21-22`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L21-L22) |
| Names: `<prefix>-<component>-vN` and module `<Prefix>.<Component>VN`. API packages: `<prefix>-api-<component>-vN`, modules under `<Prefix>.Api.<Component>VN`. This repository uses the working prefix `cvx` and `Cayvox` (D-17). | [`AGENTS.md:31-34`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/AGENTS.md#L31-L34), [`ARCHITECTURE.md:91-112`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L91-L112) |
| Category directories are navigation only and never appear in names. | [`AGENTS.md:47-48`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/AGENTS.md#L47-L48), [`packages/README.md:3-5`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/packages/README.md#L3-L5) |
| Template names are stable component terms. | [`ARCHITECTURE.md:116-117`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L116-L117) |

## 2. API and implementation split

| Rule | Source |
|---|---|
| Interfaces and exceptions are not SCU-upgradeable. A component that defines them ships a frozen API package with no templates, plus an upgradeable implementation package. | [`ARCHITECTURE.md:32-41`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L32-L41), [`AGENTS.md:35-37`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/AGENTS.md#L35-L37) |
| Template-only components get no API package. | [`AGENTS.md:36-37`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/AGENTS.md#L36-L37), [`ARCHITECTURE.md:43-45`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L43-L45) |
| An API package defines no `template`; an implementation package defines no `interface` or `exception`. `interface instance` is allowed. | [`scripts/check.sh:125-136`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/scripts/check.sh#L125-L136) |
| Helper functions stay out of frozen packages, as Splice keeps its helpers in `splice-token-standard-utils`. | [`ARCHITECTURE.md:55-61`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L55-L61) |
| Model to follow: Pausable (`openzeppelin-api-pausable-v1` and `openzeppelin-pausable-v1`). | [`ARCHITECTURE.md:47-73`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L47-L73) |

## 3. Dependencies

| Rule | Source |
|---|---|
| API packages depend only on API packages. Implementation packages do not depend on other implementation packages without an accepted architecture decision. | [`AGENTS.md:38-40`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/AGENTS.md#L38-L40), [`ARCHITECTURE.md:77-78`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L77-L78) |
| Shared pure helpers live in a utility package with no templates, interfaces, exceptions or serializable public state. | [`ARCHITECTURE.md:79-80`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L79-L80) |
| Adding a production dependency needs architecture review, because an SCU lineage cannot drop it later. | [`ARCHITECTURE.md:81-83`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L81-L83), [`CONTRIBUTING.md:99`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/CONTRIBUTING.md#L99) |
| No `daml-script` in production packages. | [`AGENTS.md:41`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/AGENTS.md#L41), [`scripts/check.sh:121-122`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/scripts/check.sh#L121-L122) |
| Consume exact, verified upstream DARs; never republish upstream interfaces under the library's namespace. | [`AGENTS.md:49-50`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/AGENTS.md#L49-L50), [`ARCHITECTURE.md:87`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L87) |
| Third-party DARs are pinned by source, version, package IDs, SHA-256 and license in `dars/manifest.yaml`, with binaries in `dars/vendor/`. | [`ARCHITECTURE.md:84-86`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L84-L86), [`dars/README.md:16-24`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/dars/README.md#L16-L24) |

## 4. Upgrades and releases

| Rule | Source |
|---|---|
| A compatible release keeps the name and raises the version. A breaking change creates a sibling `-v2` package with a `V2` module suffix. | [`ARCHITECTURE.md:114-116`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L114-L116), [`README.md:120-121`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/README.md#L120-L121) |
| An interface instance can be added under SCU, with `-Wno-template-has-new-interface-instance`, and never removed. | [`ARCHITECTURE.md:68-73`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/ARCHITECTURE.md#L68-L73), [`packages/security/api-pausable-v1/README.md:74-77`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/packages/security/api-pausable-v1/README.md#L74-L77) |
| A new field on an existing template is `Optional` and appended at the end of the record. | [`packages/security/api-pausable-v1/README.md:50-51`](https://github.com/OpenZeppelin/canton-contracts/blob/aeca01d043311d8ccc8ab7cda4d7c16e682429fa/packages/security/api-pausable-v1/README.md#L50-L51) |

## Differences

Each is a choice of this repository, kept until the library's maintainers decide otherwise.

| Difference | Why |
|---|---|
| `multi-package.yaml` pins SDK 3.4.11, and every gate runs on SDK 3.4.11, 3.5.8 and 3.5.10, selected with `DPM_SDK_VERSION`. API packages are built by SDK 3.4.11 only. | An API package's ID depends on the SDK that builds it, so one build is recorded and consumed by every SDK (D-11, `dars/api-packages.yaml`). |
| Error identifiers use the components `vault`, `registry` and `math`, and empty `meta`. | Identifiers are public API; changing them is a decision for the maintainers (D-13). |
| `tools/` holds never-released Daml Script tooling with its `-test` package, checked by `scripts/check-tools.sh` instead of the source and test trees. | A tool depends on `daml-script`, which the trees forbid in a production package. |
| `scripts/ci.sh` and the gate scripts are the contributor interface in `CONTRIBUTING.md`; package READMEs show native DPM commands. | The gates add checks the library does not have (docs/TESTING.md). |
